# Site estático

Para sites de HTML, CSS e JavaScript prontos, sem passo de build. O `scaffold.sh` sugere esta stack quando a pasta tem um `index.html` e nenhuma stack mais específica bate. Num repositório em que o site fica numa subpasta (ex.: `docs/`), ela aparece como uma aplicação do monorepo.

A rota de saúde é a própria página inicial (`/`). Sem banco, sem migração e sem pastas montadas.
